# Lindsay Meneses
Repositorio de trabajo con Claude.

Tiene instalados **agentes y skills** para mercadeo, publicidad, copywriting, branding, diseño y programación web. El índice completo está en [CATALOGO.md](CATALOGO.md).

## Estructura
- `.claude/skills/`: skills que Claude Code carga automáticamente.
- `.claude/agents/`: subagentes especializados.
- `.claude/tools/`: guías de integración con plataformas de marketing, como Google Ads, Meta, GA4 o Klaviyo.
- `.claude/settings.json`: registra catálogos adicionales de plugins (usa `/plugin` en Claude Code para ver e instalar más).
- `.claude/licenses/`: licencias de cada repositorio de origen (MIT, Apache 2.0 y GPL).
